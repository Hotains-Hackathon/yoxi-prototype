# yoxi 活動探索與拼圖獎勵提案

可直接檢視的七章提案草稿位於 [05-delivery/提案正文.md](05-delivery/提案正文.md)，公開資料與競品來源登錄於 [05-delivery/sources.md](05-delivery/sources.md)。

`BRD.md`、`MRD.md`、`PRD.md` 已整理為提案版文件；補充研究、產品取捨、來源與獨立發想放在下列目錄。

| 位置 | 用途 |
| --- | --- |
| `01-discovery/` | 待確認問題、研究與驗證計畫 |
| `02-business/` | BRD 可補入的商業定義與指標 |
| `03-market/` | MRD 可補入的市場、競品與定位 |
| `04-product/` | PRD 可補入的 MVP、流程與驗收 |
| `05-delivery/` | 提案繳交素材、來源與版本紀錄 |
| `ideas/` | 尚在發散階段的點子草稿 |

## 目前文件使用方式

1. 先閱讀 `05-delivery/提案正文.md`，它已按繳交要求整合七個章節。
2. 需要追查依據時，查看 `05-delivery/sources.md`、題目樣本分析與三份補足建議。
3. 提案中的訪談、資料抽樣、A/B 試點、插畫委託與驚喜回饋規則是後續驗證／核定事項，尚未執行或承諾。

## 原始文件與提案章節對照

`What I need to apply.md` 列出七個提案章節與 BRD/MRD/PRD 的對應。三份「補足建議」提供分章骨架，完整敘述以提案正文為準。
